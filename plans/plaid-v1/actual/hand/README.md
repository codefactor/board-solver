# Plaid v1 — Cut Plan

*Two end-grain plaid cutting boards built from cherry, walnut, and brown maple.*

Cut list for the finished design, in build order.

## 1. Warnings

| # | Lvl | Type | Message |
| --- | --- | --- | --- |
| 1 | ERROR | Over Rip | Cut list for board BC1A over-rips by ⅛″: the strips are wider than the board. |
| 2 | ERROR | Over Rip | Cut list for board BC2A over-rips by ⁷⁄₁₆″: the strips are wider than the board. |
| 3 | WARNING | Crosscut Shave | Board BC1's cut is close to the end of the board, so the saw blade will be shaving off the end with no off cut. |
| 4 | WARNING | Crosscut Shave | Board BC2's cut is close to the end of the board, so the saw blade will be shaving off the end with no off cut. |
| 5 | WARNING | Planer Gang Too Small | There aren't enough 3″ strips to gang together to safely pass through the planer without tipping over. You might need sacrificial wood to tape onto it in order to prevent movement. |
